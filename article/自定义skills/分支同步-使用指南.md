# 分支同步 (selective-sync-md) 使用指南

选择性同步 `article/` 目录，自动恢复其他所有目录。

## 核心功能

| 功能 | 说明 |
|------|------|
| 单目录同步 | 只同步 `article/` |
| 自动恢复 | 其他目录全部保持原状态 |
| 双向支持 | 任意分支间同步 |

## 使用场景

当需要在不同分支间同步 article 文档，但不想影响 Docker 配置、项目文档时使用。

## 工作流程

```
合并目标分支 → 恢复非 article 目录 → 显示 article 变更 → 确认提交
```

## 脚本位置

```bash
/Users/mac/wwwroot/docker_env/scripts/selective-sync-md.sh
```

## 使用方法

### 从 mobile-reader 同步到 master

```bash
cd /Users/mac/wwwroot/docker_env
git checkout master
./scripts/selective-sync-md.sh mobile-reader

# 检查变更
git status

# 确认后提交
git commit -m "sync: article from mobile-reader"
```

### 从 master 同步到 mobile-reader

```bash
cd /Users/mac/wwwroot/docker_env
git checkout mobile-reader
./scripts/selective-sync-md.sh master

# 或在 worktree 中运行
cd /Users/mac/wwwroot/docker_env/.worktrees/mobile-reader
./scripts/selective-sync-md.sh master

# 确认后提交
git commit -m "sync: article from master"
```

## 恢复列表

合并时以下内容会被自动恢复（不受目标分支影响）：

| 类型 | 内容 |
|------|------|
| Docker 配置 | `middleware/`, `examples/`, `local/`, `scripts/` |
| 项目文档 | `docs/` |
| 根目录文件 | `CLAUDE.md`, `README.md`, `.gitignore` |
| Docker 文件 | `.dockerignore`, `docker-compose.yml` |
| 配置文件 | `.env.example`, `*.conf`, `Dockerfile` |

**仅同步**：`article/` 目录

## 命令参数

```bash
./scripts/selective-sync-md.sh <目标分支名>
```

## 错误处理

| 情况 | 命令 |
|------|------|
| 合并冲突 | `git merge --abort` |
| 取消合并 | `git merge --abort` |
