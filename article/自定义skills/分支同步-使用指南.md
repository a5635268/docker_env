# 分支同步 (selective-sync-md) 使用指南

选择性同步 `article/` 目录，自动恢复其他所有目录。

## 核心功能

| 功能 | 说明 |
|------|------|
| 单目录同步 | 只同步 `article/` |
| 双向兼容 | master ↔ worktree 都能正确工作 |
| 自动清理 | 合并带来的其他文件自动删除 |

## 使用场景

| 场景 | 说明 |
|------|------|
| master → mobile-reader | 同步 master 新增的 article 文档 |
| mobile-reader → master | 合并 mobile-reader 的 article 变更 |
| worktree 中运行 | 直接在 worktree 目录调用脚本 |

## 工作流程

```
合并目标分支 → 取消暂存 → 恢复工作目录 → 清理未跟踪 → 只取 article → 提交
```

## 脚本位置

```bash
/Users/mac/wwwroot/docker_env/scripts/selective-sync-md.sh
```

## 使用方法

### 在主仓库 (master) 同步 mobile-reader

```bash
cd /Users/mac/wwwroot/docker_env
git checkout master
./scripts/selective-sync-md.sh mobile-reader

# 检查变更
git status --short

# 确认后提交
git commit -m "sync: article from mobile-reader"
```

### 在 worktree (mobile-reader) 同步 master

```bash
cd /Users/mac/wwwroot/docker_env/.worktrees/mobile-reader
/Users/mac/wwwroot/docker_env/scripts/selective-sync-md.sh master

# 检查变更
git status --short

# 确认后提交
git commit -m "sync: article from master"
```

## 工作原理

脚本通过"合并 → 取消 → 清理 → 只取 article"四步：

| 步骤 | 命令 | 作用 |
|------|------|------|
| 1. 合并 | `git merge --no-commit` | 获取目标分支变更 |
| 2. 取消 | `git reset HEAD` | 取消所有暂存 |
| 3. 恢复 | `git checkout -- .` | 恢复工作目录 |
| 4. 清理 | `git clean -fd` | 删除新增目录 |
| 5. 提取 | `git checkout $TARGET -- article/` | 只取 article |

**仅同步**：`article/` 目录

## 命令参数

```bash
./scripts/selective-sync-md.sh <目标分支名>
```

## 错误处理

| 情况 | 命令 |
|------|------|
| 合并冲突 | `git merge --abort` |
| 取消合并 | `git merge --abort` |
