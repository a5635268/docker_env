# 飞书一键同步 (lark-sync) 使用指南

同步本地 Markdown 文档到飞书知识库，自动处理图片上传。

## 核心功能

| 功能 | 说明 |
|------|------|
| 路径解析 | 从文件路径自动提取知识库名（父目录名） |
| 图片处理 | 本地图片/网络图片自动上传 OSS，飞书图片保留 |
| 知识库匹配 | 自动查找对应知识库，不存在则提示创建 |

## 触发方式

```
同步 docs/xxx.md 到飞书
把本地文档同步到飞书知识库
上传 Markdown 到飞书
```

## OSS 配置

图片上传到阿里云 OSS，配置存储在 skill 内部脚本中。

**上传 URL 格式：**
```
https://moumoufarm.oss-cn-shanghai.aliyuncs.com/caiwen/feishu/{timestamp}_{md5hash}_{filename}
```

## 图片处理规则

| 类型 | 示例 | 处理方式 |
|------|------|---------|
| 本地相对路径 | `./images/foo.png` | 解析绝对路径后上传 OSS |
| 本地绝对路径 | `/Users/.../foo.png` | 直接上传 OSS |
| 网络图片（非飞书） | `https://example.com/foo.png` | 下载后上传 OSS |
| 飞书图片 | `https://xxx.feishu.cn/...` | 直接保留 |

**飞书域名判断：** 包含 `feishu.cn` 或 `larksuite.com`

## 工作流程

```
用户请求: 同步 docs/工具篇/ticktick-mcp-guide.md
                    ↓
1. 解析路径 → 知识库名="工具篇", 文档标题="ticktick-mcp-guide"
                    ↓
2. 读取 Markdown → 检测图片引用
                    ↓
3. 图片处理 → 本地/网络图片上传 OSS，飞书图片保留
                    ↓
4. 查找知识库 → wiki spaces list 匹配 name
                    ↓
5. 创建文档节点 → wiki +node-create
                    ↓
6. 写入内容 → docs +update --mode overwrite
                    ↓
7. 返回文档链接 → https://feishu.cn/wiki/{node_token}
```

## 路径解析规则

从文件路径提取知识库名和文档标题：

```
路径: docs/工具篇/ticktick-mcp-guide.md
解析:
  - 知识库名 = 父目录名 = "工具篇"
  - 文档标题 = basename(去.md) = "ticktick-mcp-guide"
```

**特殊情况：**
- 单层路径（`docs/readme.md`）：知识库名 = "docs"
- 多层路径（`docs/ai编程/notes/guide.md`）：知识库名 = 最近父目录 = "notes"

## 命令参考

### 列出知识库

```bash
lark-cli wiki spaces list --as user
```

### 创建文档节点

```bash
lark-cli wiki +node-create --space-id <SPACE_ID> --title "<TITLE>" --as user
```

### 写入文档内容

```bash
lark-cli docs +update --doc "<obj_token>" --mode overwrite --markdown "<CONTENT>" --as user
```

### 上传图片到 OSS

```bash
# 安装 OSS SDK
pip3 install --break-system-packages oss2

# 上传图片
python3 ~/.claude/skills/lark-sync/scripts/oss-upload.py --file /path/to/image.png

# 返回
OK: https://moumoufarm.oss-cn-shanghai.aliyuncs.com/caiwen/feishu/xxx.png
```

## 飞书 Markdown 图片格式

飞书 `<image>` 标签只支持 `url` 属性：

```markdown
<!-- ✅ 有效 -->
<image url="https://moumoufarm.oss-cn-shanghai.aliyuncs.com/caiwen/feishu/xxx.png" width="800"/>

<!-- ❌ 无效（会被跳过） -->
<image file_token="filcnXXX"/>
```

**优势：**
- 图片位置保留在原文 Markdown 位置
- 不需要使用 `docs +media-insert` 插入到文档末尾

## 前置要求

| 要求 | 检查命令 |
|------|---------|
| 用户已授权 | `lark-cli auth status` |
| 所需 scopes | `wiki:space:read`, `wiki:node:create`, `docx:document:create`, `docx:document:write_only` |
| OSS SDK | `pip install oss2` (Python 3.12+) |

## 错误处理

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| `oss2 not found` | OSS SDK 未安装 | `pip3 install oss2` |
| `file not found` | 本地图片不存在 | 检查图片路径 |
| `download failed` | 网络图片下载失败 | 检查 URL |
| `upload failed` | OSS 上传失败 | 检查 OSS 配置和权限 |
| `OSS auth failed` | OSS Key 无效 | 检查 Access Key |
| 知识库不存在 | 匹配失败 | 提示创建或选择其他知识库 |

## Python 版本注意事项

Mac 系统有多个 Python 版本：

```bash
# 系统 Python
/usr/bin/python3 → Python 3.9.6

# Homebrew Python
/usr/local/bin/python3.12 → Python 3.12

# OSS SDK 安装在 Python 3.12
/usr/local/opt/python@3.12/Frameworks/Python.framework/Versions/3.12/bin/python3.12 scripts/oss-upload.py --file xxx
```
