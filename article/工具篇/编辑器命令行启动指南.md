# macOS 编辑器命令行启动指南

## 工具简介

在 macOS 上，常用的编辑器可以通过命令行快速启动，提高开发效率。本文档整理了常见编辑器的启动方式和别名配置。

---

## 编辑器启动命令

| 编辑器 | 命令行启动 | 说明 |
|--------|-----------|------|
| **Sublime Text** | `subl` | 默认自动添加到 PATH |
| **Antigravity** | `antigravity` 或 `agy` | 提供完整命令和简短别名 |
| **Cursor** | `cursor` | 新版自动添加到 PATH |
| **PhpStorm** | `pstorm` | 需手动配置命令行工具 |
| **Obsidian** | `open -a "Obsidian"` | 通过 open 命令启动 |
| **Typora** | `open -a "Typora"` | 通过 open 命令启动 |

---

## 基本用法

### Sublime Text

```bash
# 打开文件
subl file.txt

# 打开目录
subl /path/to/project

# 打开当前目录
subl .
```

### Antigravity

```bash
# 使用完整命令
antigravity file.txt

# 使用简短别名
agy .

# 打开指定目录
agy /path/to/project
```

### Cursor

```bash
# 打开文件或目录
cursor .

# 打开指定项目
cursor /path/to/project
```

### PhpStorm

```bash
# 手动配置方式（在 PhpStorm 内）
# Tools → Create Command-line Launcher

# 使用 open 命令启动
open -a "PhpStorm" file.php
```

### Obsidian / Typora (通过 open 命令)

```bash
# 打开应用
open -a "Obsidian"
open -a "Typora"

# 打开指定文件
open -a "Typora" document.md
open -a "Obsidian" vault/
```

## 别名配置

### 推荐配置

在 `~/.zshrc` 中添加以下别名：

```bash
# 编辑器别名
alias obsidian='open -a "Obsidian"'
alias typora='open -a "Typora"'
```

### 配置生效

```bash
# 立即生效
source ~/.zshrc

# 或重新打开终端窗口
```

## 命令检查

### 检查命令是否可用

```bash
# 检查命令是否存在
which subl cursor antigravity agy pstorm

# 查看命令路径
ls -la /usr/local/bin | grep -E "subl|cursor|antigravity|agy|pstorm"
```

### 命令不存在时的处理

如果命令不存在，使用 `open -a "应用名"` 是最可靠的启动方式：

```bash
open -a "Sublime Text"      # Sublime Text
open -a "Cursor"            # Cursor
open -a "PhpStorm"          # PhpStorm
open -a "Obsidian"          # Obsidian
open -a "Typora"            # Typora
open -a "Antigravity"       # Antigravity
```

## 使用场景

### 场景 1：快速打开项目

```bash
# 使用 yazi 定位后用编辑器打开
cd /path/to/project && cursor .

# 直接打开特定文件
subl ~/.zshrc
typora README.md
```

### 场景 2：配合脚本使用

```bash
# 在脚本中启动编辑器
#!/bin/bash
cursor "$(git rev-parse --show-toplevel)"

# 编辑配置文件后立即生效
subl ~/.zshrc && source ~/.zshrc
```

### 场景 3：多编辑器协作

```bash
# 用 Typora 编辑 Markdown，用 Cursor 编写代码
typora docs/
cursor src/
```

## 注意事项

1. **Nerd Font 支持**: 某些编辑器（如 Antigravity）可能需要 Nerd Font 字体支持
2. **PATH 检查**: 命令行工具路径通常在 `/usr/local/bin`
3. **open 命令**: macOS 内置命令，最可靠的启动方式
4. **别名持久化**: 别名需写入 `~/.zshrc` 或 `~/.bashrc` 才能永久生效
