## 会话管理

| 命令 | 功能描述 | 使用场景 |
|------|----------|---------|
| `/clear` `/reset` `/new` | 清除会话历史，释放上下文空间 | 对话过长影响性能时，或开始全新任务 |
| `/branch [name]` `/fork` | 在当前点创建会话分支 | 尝试不同实现方案，不影响主对话历史 |
| `/rename [name]` | 重命名当前会话 | 给重要会话命名便于后续恢复查找 |
| `/resume [session]` `/continue` | 恢复之前的会话 | 继续中断的工作，或切换到历史会话 |
| `/export [filename]` | 导出当前会话为纯文本 | 保存对话记录，分享或归档 |

## 使用技巧

1. **输入 `/` 按 Tab** — 可过滤命令列表，快速找到目标命令
2. **命令可串联** — 如 `/model sonnet` 切换模型，`/compact` 压缩对话
3. **部分命令有别名** — 如 `/clear` = `/reset` = `/new`
4. **可用命令取决于环境** — 平台、订阅计划、配置会影响可见命令

## 内置 Skill (Bundled Skills)

以下是通过 slash 命令调用的内置技能，本质是预设 prompt：

| 命令 | 功能 |
|------|------|
| `/loop` | 循环执行任务或定时轮询 |
| `/simplify` | 代码简化审查 |
| `/changelog-generator` | 从 git commits 生成变更日志 |

---

## 注意事项

- **自定义 Skills** (如 `/zcf:*`, `/lark-*`, `/superpowers:*`) 由插件或用户配置提供，非内置命令
- **命令帮助** — 输入命令后不加参数通常显示该命令的详细用法
- **版本差异** — 不同版本可能有不同命令集，本文档基于 v2.1.104
