# Gemini Voyager 插件安装指南

Gemini Voyager 是一个非常实用的 Gemini 增强插件，不过近期由于名称中包含 "Gemini" 字样，它已暂时从 Chrome 网上应用店下架了。

不过别担心，这只是名字的问题，插件本身是安全、开源的。你可以通过下面这些方式下载和安装：

## 各浏览器安装指南

### Chrome / Edge 等 Chromium 浏览器

由于商店已下架，推荐通过 **开发者模式** 从 GitHub 安装，这样还能第一时间用上最新版本。

1. **下载文件**：访问 GitHub 项目页的 [Releases 页面](https://github.com/Nagi-ovo/gemini-voyager/releases)，下载最新版的 `gemini-voyager-chrome-v*.zip` 文件。
2. **解压文件**：将下载的 ZIP 包解压到一个**不会移动或删除**的文件夹（比如放在 `D:\Extensions\` 下）。
3. **加载插件**：
   - 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
   - 打开右上角的 **"开发者模式"**。
   - 点击左上角的 **"加载已解压的扩展程序"**，选择刚才解压的文件夹即可。

> **温馨提示**：如果你以前安装过且插件还在，可以去扩展程序管理页面尝试手动启用它，或许还能继续用。

### Firefox 浏览器

Firefox 用户比较幸运，可以直接安装 `.xpi` 文件。

- 访问 GitHub Releases 页面，下载 `gemini-voyager-firefox-v*.xpi` 文件，Firefox 通常会自动识别并完成安装。

### Safari 浏览器

Safari 的安装步骤稍微多一点。

- 在 GitHub Releases 页面下载 `gemini-voyager-v*.dmg` 文件。
- 打开并安装应用。需要注意，由于 Safari 的限制，**去水印、图片导出和云同步功能**暂时无法使用。

## 插件功能介绍

装上之后，你的 Gemini 界面会多出不少实用功能：

| 功能 | 说明 |
|------|------|
| 文件夹管理 | 给对话分类，直接拖拽就能整理，告别"AI 杂物间" |
| 时间轴导航 | 右侧显示对话节点，点击跳转任意位置，长对话找信息很方便 |
| 内容导出 | 支持导出为 JSON、Markdown、PDF 等格式 |
| 下载无水印图片 | 一键下载 Nano Banana 生成的图片，不带 Gemini 水印 |
| 提示词库 | 保存常用提示词，快速调用 |
